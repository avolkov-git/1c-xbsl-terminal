# Terminal surface
Mode: Operate. Target: ui/terminal.ts, ui/terminal.css.
Task: open Bash and work without leaving the IDE. Pinned reference: VS Code.
States: empty, starting, running, exited, failure; multiple sessions are selectable.
No output is treated as HTML. Narrow panels keep the terminal usable; toolbar
controls have accessible names and visible focus. Light/dark themes inherit host.
